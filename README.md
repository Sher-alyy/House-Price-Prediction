# Task 6 — House Price Prediction

## Task Name

House Price Prediction using Linear Regression

## Objective

The objective of this project is to develop a machine learning model that predicts house prices using property-related features. This task focuses on regression modeling, data preprocessing, and performance evaluation.

## Dataset

House Price Dataset (CSV format)

## Tools and Technologies

* Python
* Pandas
* Matplotlib
* Seaborn
* Scikit-learn
* Google Colab / Jupyter Notebook

## Project Workflow

1. Data loading and preprocessing
2. Exploratory Data Analysis (EDA)
3. Feature and target selection
4. Model training using Linear Regression
5. Model evaluation using MAE and MSE
6. Visualization of predicted vs actual prices

## Results

The Linear Regression model was able to learn relationships between housing features and price. Evaluation metrics and visualization indicate reasonable prediction performance.

## Conclusion

This project demonstrates how regression models can be applied to real estate data for price estimation. Future improvements may include feature engineering and advanced regression techniques.
